# EKIDEN.AI Docs

Public documentation for EKIDEN.AI v3, served at https://docs.ekiden.ai/ by GitHub Pages.

```sh
node .yarn/releases/yarn-4.5.3.cjs install
node .yarn/releases/yarn-4.5.3.cjs dev     # local preview
node .yarn/releases/yarn-4.5.3.cjs build   # docs/.vitepress/dist
```

This repository is public. Never put anything internal here: no passwords, keys, deploy plans, permissions, project IDs or people's roles. Pages are written in Japanese first, with English under `docs/en/`.

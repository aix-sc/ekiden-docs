# EKIDEN.AI Docs

Public documentation for EKIDEN.AI v3, served at https://docs.ekiden.ai/ by GitHub Pages.

```sh
node .yarn/releases/yarn-4.5.3.cjs install
node .yarn/releases/yarn-4.5.3.cjs dev     # local preview
node .yarn/releases/yarn-4.5.3.cjs build   # docs/.vitepress/dist
```

This repository is public. Never put anything internal here: no passwords, keys, deploy plans, permissions, project IDs or people's roles. The Japanese guide is a single page (`docs/index.md`) so that readers can search it with the browser's find; add new topics as sections there, not as new pages. English is a single page too (`docs/en/index.md`) with the same sections; keep the two in step.
